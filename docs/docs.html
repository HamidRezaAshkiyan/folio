Why Folio exists & how to use it.

Folio was built for people who love the calm focus of a physical Bullet Journal, yet spend much of their day in front of a keyboard. Here is the philosophy behind Folio and a practical guide to getting started.

1. Why Folio Exists 2. Interfaces 3. Settings & Vault 4. Daily Workflow 5. CLI & I/O 6. Markdown Format
01 · Motivation

Why Folio Exists

Paper notebooks are extraordinary for thinking clearly: no notifications, no infinite backlogs, and a tactile rhythm that slows your mind down. Yet real life is messy — sometimes your notebook is in your backpack, you're mid-command in a terminal, or you want to search across six months of notes in a second.

Most digital task managers try to replace paper with complex databases, cloud subscriptions, and gamified streaks. Folio takes the opposite stance: it is a companion to your physical notebook, not a competitor.

Paper-First Companion

Every entry tracks whether it has been transcribed to your physical spread ([paper:no] → [paper:ok]) and links to your real notebook page number (p. 42).

Plain Markdown Forever

No proprietary database, no cloud account. Your journal lives as clean .md files with YAML frontmatter and [[wikilinks]] — natively readable in Obsidian or any editor.

Fast & Bilingual

A single lightweight Rust binary with a keyboard-driven TUI, a native Desktop GUI with full Persian/Arabic RTL support, an embedded Web GUI, and instant shell logging.

New to the Bullet Journal method itself? Read the minimal Bullet Journal Guide first for a 3-minute overview of Rapid Logging, Signifiers, and Migration.
02 · One Binary, Four Ways to Work

Choosing Your Interface

Every interface reads and writes the exact same Markdown vault on disk, so you can switch freely between them throughout the day.

Terminal UI — folio --tui

Default mode when running folio. A 6-pane Ratatui interface with Vim-inspired navigation (j/k, i, /, :w, :q) and mouse support.

Native Desktop GUI — folio --gui

Built with Iced. Features Dark & Light themes, live LTR / AUTO / RTL Persian mode, Migration Triage, Global Paper Queue, AM/PM Reflect, and an in-app Settings panel (⌘,).

Embedded Web GUI — folio --web

Starts a local HTTP server (default 127.0.0.1:3420) and opens Folio in your browser — great for side-by-side browser workflows.

CLI & Obsidian Plugin

Capture a thought in one second with folio log ". Buy coffee beans", or open the same vault folder in Obsidian with the companion plugin.

03 · Configuration

Settings & Vault Folder

By default, Folio stores your Markdown vault at ~/Obsidian/BuJo-Vault and saves preferences to ~/.config/folio/config.toml (or the platform config directory on macOS/Windows).

Changing Settings in the App

  • Native GUI (folio --gui): Click Settings in the top bar or press ⌘, (Ctrl+,). You can type or browse for a new Vault Folder, set the default notebook page, customize default Spaces, switch Dark/Light theme, and toggle LTR/AUTO/RTL direction & Persian fonts.
  • Web GUI (folio --web): Click Settings in the top bar to open the Settings dialog. Saving updates config.toml and immediately switches to the new vault folder.

Vault Path Resolution Order

When Folio starts, it resolves your vault directory in this priority order:

Priority Source Example
1 (Highest) CLI flag folio --vault ~/Notes/MyBuJo --gui
2 Environment variable FOLIO_VAULT=~/Notes/MyBuJo folio
3 Config file (config.toml) vault_path = "/Users/you/Obsidian/BuJo-Vault"
4 (Default) Built-in default ~/Obsidian/BuJo-Vault 
# ~/.config/folio/config.toml
vault_path = "/Users/you/Obsidian/BuJo-Vault"
notebook_page = 42
default_spaces = ["Studio & Work", "Reading & Study", "Personal"]
rtl_mode = "auto"        # "auto" | "ltr" | "rtl"
gui_theme = "dark"       # "dark" | "light"
persian_font = "vazirmatn" # "vazirmatn" | "dastkhat"
04 · Practice

A Practical Daily Workflow

Morning — Set Intentions

Launch folio --gui or folio --tui. Open Triage (⌘M) to review unfinished actions from previous days: migrate what matters to today, schedule later items to the Future Log, or cancel stale ones.

During the Day — Rapid Log

Press ⌘N (GUI) or i (TUI) and type with a prefix: . for Action, o for Event, = for Emotion, - for Note. Add * for Priority or ! for Inspiration (e.g. *. Ship v1.9).

Evening — Carry to Paper

Open your physical notebook to your current spread, set the page number (p. 42), and transcribe entries marked [paper:no]. Press m / M (or click [paper:no]) to flip them to [paper:ok].

Weekly & Monthly — Review

Press w or r in the TUI (or click Weekly / M.Rev in the GUI, or run folio review weekly) to generate a structured Markdown review summary under Reviews/.

05 · Command Line

CLI Commands & Import / Export

# Rapid-log directly from any terminal
folio log ". Finalize studio lighting sketch"
folio log "o Coffee with Maya at 09:30"
folio log "= Calm and focused after morning walk"
folio log -s "Reading & Study" "- Finish A Pattern Language ch. 4"

# Search across Daily Notes, Spaces, Reviews, and #tags
folio search "#architecture"

# Refresh Master Index (Index.md) or open Monthly Log
folio index
folio monthly

# Generate Weekly or Monthly Review
folio review weekly
folio review monthly

# Import from Apple Notes, Obsidian, Notion, CSV, or JSON
folio import ~/Desktop/notes.md
folio export --format json --output today.json
06 · Data Ownership

Vault Structure & Markdown Format

Every file in your vault is plain UTF-8 Markdown. If you ever stop using Folio, your entire journal remains completely readable and searchable. 

~/Obsidian/BuJo-Vault/
├── Index.md
├── Future Log.md
├── Daily Notes/
│   ├── 2026-11-25.md
│   ├── 2026-11-monthly.md
│   └── 2026-11-index.md
├── Spaces/
│   ├── studio-work.md
│   ├── reading-study.md
│   └── personal.md
└── Reviews/
    ├── 2026-W48.md
    └── 2026-11-review.md
---
date: 2026-11-25
page: 42
tags:
  - bujo
  - daily
---
*. [08:15] Finalize lighting sketch [paper:no]
o [09:30] Coffee with [[Maya]] [paper:ok]
= [10:45] Calm after walking [paper:no]
!- [11:10] Small repairs build living spaces [paper:no]
× [11:25] Order ink refill [paper:ok]
